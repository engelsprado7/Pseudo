# Área de un rectángulo

Leé la base y la altura de un rectángulo y escribí su área.

Podés escribir los mensajes que quieras para pedir los datos. Lo único que se
revisa es que en algún momento aparezca una línea con el área.

```
El área es: <resultado>
```

Comparación: contiene

## Caso: valores enteros

```entrada
5
3
```

```salida
El área es: 15.0
```

## Caso: con decimales

```entrada
2.5
4
```

```salida
El área es: 10.0
```

## Caso: base 1

```entrada
1
7
```

```salida
El área es: 7.0
```
