# Tabla de multiplicar

Leé un número entero y escribí su tabla de multiplicar del 1 al 10, una línea
por producto, con este formato exacto:

```
3 x 1 = 3
3 x 2 = 6
```

Comparación: normalizada

## Caso: tabla del 3

```entrada
3
```

```salida
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
```
