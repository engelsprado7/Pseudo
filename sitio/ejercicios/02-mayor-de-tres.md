# El mayor de tres números

Leé tres números enteros y escribí el mayor de los tres.

La salida tiene que ser exactamente una línea con el número, sin ningún otro
texto. Si hay empate, el mayor es ese número igual.

Comparación: exacta

## Caso: el primero es el mayor

```entrada
9
4
7
```

```salida
9
```

## Caso: el del medio

```entrada
2
15
6
```

```salida
15
```

## Caso: el último

```entrada
3
1
8
```

```salida
8
```

## Caso: todos iguales

```entrada
5
5
5
```

```salida
5
```

## Caso: negativos

```entrada
-9
-2
-40
```

```salida
-2
```
