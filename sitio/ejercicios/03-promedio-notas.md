# Promedio de notas

Leé primero cuántas notas vas a procesar, después las notas una por una, y
escribí el promedio redondeado a dos decimales junto con la clasificación.

La clasificación es: 9 o más "Excelente", 7 o más "Aprobado", 5 o más
"Recuperación", menos de 5 "Reprobado".

Comparación: contiene
Decimales: 2

## Caso: tres notas altas

```entrada
3
9
10
8
```

```salida
Promedio: 9.00
Excelente
```

## Caso: justo en el límite de aprobado

```entrada
2
7
7
```

```salida
Promedio: 7.00
Aprobado
```

## Caso: una sola nota baja

```entrada
1
3
```

```salida
Promedio: 3.00
Reprobado
```

## Caso: promedio con decimales

```entrada
3
8
9
9
```

```salida
Promedio: 8.67
Aprobado
```
